Documentation changes

Changes in this revised copy of the Boring Log Viewer documentation, checked against the code at commit eec1e4a (Oct 10, 2026). The last nine rows (Oct 20, 2026) add the Excel import and move the links to the top bar, for the logs-only viewer. In the pages, red highlighted text is new or changed and red struck-through text is removed. Open the documentation.
